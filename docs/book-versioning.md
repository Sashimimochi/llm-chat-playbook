# 書籍版のコードを公開する

## バージョン方針

- `main` は最新版の開発を進めるブランチとし、旧版専用ブランチや旧版コードの複製ディレクトリは維持しません。
- 2024年版のコードは `v1.x` 系のタグで固定済みです。現在の最新タグは `v1.5.0` です。
- 2026年版はメジャーバージョンを上げ、`v2.x` 系のタグで管理します。2026年版の最初の公開時に、内容に応じた具体的なバージョン番号を決定します。
- 2024年版のタグを新たに作り直したり、`book-2024` / `book-2026` のような年号タグを追加したりしません。

## Release作成手順

1. 書籍配布物との照合結果を確認し、対象コミットSHA（40桁）を記録します。
2. 2026年版のリリースでは、`v2.0.0` など `v2.x.y` 形式のタグ名を決定します。
3. GitHubの **Actions → Publish Book Version Release → Run workflow** を開き、タグ名と照合済みSHAを入力して実行します。
4. ワークフローがタグとReleaseを作成したら、Releaseページのタグ、コミットSHA、ソースアーカイブを確認します。
5. READMEなどの案内先から [GitHub Releases](https://github.com/Sashimimochi/llm-chat-playbook/releases) へアクセスできることを確認します。

ワークフローは `v2.x.y` 形式以外のタグ、存在しないコミット、公開済みReleaseへの上書きを拒否します。同名タグが存在する場合も、指定したSHAと異なれば失敗し、既存タグを移動しません。このワークフローでは2026年版の `v2.x` 系タグのみを作成できます。

## タグ作成時の注意

タグを作成する前に、配布したソース、書籍掲載コード、当時のセットアップ手順とGit履歴を照合し、コミットSHAを確定します。コミット日時だけで推測してタグを作成してはいけません。

一度公開したタグやReleaseは付け替え・削除しません。既存の同名タグ／Releaseがある場合は、参照先と公開状態を調べてから手動で判断します。
