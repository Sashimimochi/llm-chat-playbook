# 書籍版のコードを公開する

## 運用方針

- `main` は最新版の開発を進めるブランチとし、旧版専用ブランチや旧版コードの複製ディレクトリは維持しません。
- 書籍の配布時点のコードを `book-2024`、`book-2026` のタグとGitHub Releaseで固定します。
- タグを作成する前に、配布したソース、書籍掲載コード、当時のセットアップ手順とGit履歴を照合し、コミットSHAを確定します。コミット日時だけで推測してタグを作成してはいけません。
- 一度公開したタグやReleaseは付け替え・削除しません。既存の同名タグ／Releaseがある場合は、参照先と公開状態を調べてから手動で判断します。

## Release作成手順

1. 書籍配布物との照合結果を確認し、対象コミットSHA（40桁）を記録します。
2. GitHubの **Actions → Publish Book Version Release → Run workflow** を開き、タグ名と照合済みSHAを入力して実行します。
3. ワークフローがタグとReleaseを作成したら、Releaseページのタグ、コミットSHA、ソースアーカイブを確認します。
4. READMEから [GitHub Releases](https://github.com/Sashimimochi/llm-chat-playbook/releases) へ案内します。

ワークフローは、許可されたタグ名以外の指定、存在しないコミット、公開済みReleaseへの上書きを拒否します。同名タグが存在する場合も、指定したSHAと異なれば失敗し、既存タグを移動しません。

## 現在の保全状況

`book-2024` の対象コミットは、配布コードとの照合が終わるまで確定扱いにしません。照合前にタグやReleaseを作成すると、読者が取得するコードが書籍の掲載内容と一致しないおそれがあります。
